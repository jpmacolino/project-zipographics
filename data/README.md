# data/

Generated by `uv run python scripts/build_data.py`. Everything here except this README is
gitignored and must never be committed (public repo; no data files over 1 MB).

Contents (see `docs/SPEC.md` section 4 and `docs/DECISIONS.md`, "Phase 4"):

- `raw/`: cached raw Census API responses and boundary downloads (never contain the API key;
  files are named by a hash of the key-free URL). About 200 MB; reused unless `--refresh`.
- `zcta_profile.parquet`: one row per ZCTA (33,772 for ACS 2020-2024), every registry variable as
  `<ID>_e` / `<ID>_m` (estimate / margin of error, nulls for suppressed values), `<ID>_code` for
  medians (`top` / `bottom` / `none`), plus state, county and city. ZIPs are 5-character text.
- `benchmarks.parquet`: the same variables for the nation, every state and every county.
  Connecticut ZCTAs have no county benchmark (the ACS uses planning regions).
- `zcta_geo.parquet`: simplified ZCTA polygons for the map (GeoParquet, EPSG:4326). The shapes are
  indicative, not survey-grade; island-area ZCTAs and two New York ZCTAs with no ACS data are dropped.
- `metadata.json`: source URLs (key-free), ACS vintage, build timestamp, resolved variable list
  (with Census labels), row counts, coverage per variable and its basis, sentinel and null counts,
  top/bottom-code cross-check, county-benchmark gaps and the map note.

Check the artifacts after a build with `uv run pytest -m data`. Set `ZIPOGRAPHICS_DATA_DIR` to
point the app and those tests at another folder.
