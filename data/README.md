# data/

Generated by `uv run python scripts/build_data.py`. Everything here except this README is
gitignored and must never be committed (public repo; no data files over 1 MB).

Planned contents (see `docs/SPEC.md` section 4):

- `raw/`: cached raw Census API responses and boundary downloads (never contain the API key)
- `zcta_profile.parquet`: one row per ZCTA, every ACS estimate with its margin of error and flags
- `benchmarks.parquet`: the same variables for every state, county and the nation
- `zcta_geo.parquet`: simplified ZCTA polygons for the map (GeoParquet)
- `metadata.json`: source URLs (key-free), ACS vintage, build timestamp, variable list, row counts
